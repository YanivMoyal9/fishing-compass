# מצפן הדייג

**איפה, מתי ועם מה לדוג** — אפליקציית רשת (PWA) לדיג מהחוף בישראל: תחזית ומדד פעילות לכל 115 חופי הדיג, התחזית והאזהרות הרשמיות, 51 מיני דגים (כולל דגי זהירות), "איפה לדוג את דג X", ארסנל דמויים עם צבעים ומשקלים, ויומן תפיסות. בלי שרת ובלי build.

## האתר החי
**https://yanivmoyal9.github.io/fishing-compass/**

מתפרסם אוטומטית מ-`main` (GitHub Pages). הכתובות הישנות (`lure-fishing-guide`, `fishing-israel`) הושבתו.

## מה יש באפליקציה
| לשונית | מה מציגה |
|--------|----------|
| **היום** | לחוף שנבחר: 3 סשנים (בוקר, צהריים, ערב) עם מדד פעילות 0–100 ופירוט "למה", שכבת המים (עליונים/תחתון), דגים ודמויים לשכבה, גאות, אור ראשון ואחרון, ונוחות דיג לפי שעה |
| **חופים** | דירוג כל החופים ליום ולסשן, לפי אזור |
| **דגים** | דגים בעונה בחוף (לפי סוג החוף, החודש וטמפ׳ המים), לוח עונות, גודל מינימלי ומינים מוגנים |
| **דמויים** | ארסנל הז׳רז׳ור: 11 דמויים עם הדגמת עבודה, סינון וטופס הצעות |
| **יומן** | תפיסות עם החוף, הדמוי, האורך והמרחק מהחוף, ותנאי הים באותה שעה. ייצוא CSV |

## מקורות הנתונים
- **Open-Meteo** (חי, בלי מפתח): לחץ, רוח, משקעים, גלים, טמפ׳ מים וגובה פני הים (לגאות).
- **StormGlass** (שכבת דיוק): `data/sg.json` מתעדכן פעם ביום ממחשב הבית ונדחף למאגר. מפתח ה-API **לא** נמצא במאגר.
- **SunCalc** (`vendor/suncalc.js`, BSD): שחר ודמדומים ימיים, זריחת ושקיעת ירח.
- **קואורדינטות החופים**: OpenStreetMap / ויקיפדיה.
- **חוק**: תקנות הדיג וחוברת המידע לדייג של רט״ג (2024).
- **רשמי**: השירות המטאורולוגי (תחזית ים ל-5 אזורים ואזהרות) ורשות המים דרך data.gov.il (מפלס הכנרת).
- **חניה ועומקים**: OpenStreetMap (חניונים עד 800 מ׳) ו-EMODnet (פרופיל עומק).

## קבצים
| קובץ | תפקיד |
|------|-------|
| `index.html`, `compass.css`, `compass.js` | המבנה, העיצוב והממשק של המצפן |
| `engine.js` | חלונות הסשן, שכבת המים, מדד הפעילות (ים / כנרת), נוחות שעתית, דגים ודמויים לחוף |
| `forecast.js` | שליפת Open-Meteo לכל קבוצת נתונים ושילוב קובץ StormGlass |
| `data/species.js` | טבלת המינים: עונות, שכבה, דמויים, טמפ׳ מועדפת, גודל מינימלי |
| `data/beaches.js`, `data/groups.json` | 115 החופים (חניה מ-OSM, עומקים מ-EMODnet) ו-23 נקודות נתוני הים |
| `data/official.json` | תחזית הים הרשמית, אזהרות ומפלס הכנרת (פעמיים ביום ממחשב הבית) |
| `data/sg.json` | קובץ StormGlass היומי |
| `script.js`, `styles.css`, `fixes.css`, `bubbles.js` | ארסנל הז׳רז׳ור |
| `admin.html`, `supabase-*.sql` | ניהול הצעות הדמויים (Supabase) |
| `sw.js`, `manifest.webmanifest` | התקנה כאפליקציה ועבודה בלי רשת |

## עדכון גרסה
בכל שינוי בקבצי האפליקציה: להעלות את `VERSION` ב-`sw.js` ואת ה-`?v=` של הקובץ שהשתנה ב-`index.html` וב-`sw.js`.

> ניהול הצעות הדמויים (`admin.html`) מתחבר ל-Supabase עם הפניה לכתובת הנוכחית — אחרי שינוי הכתובת צריך להוסיף את `https://yanivmoyal9.github.io/fishing-compass/admin.html` ב-Supabase תחת Authentication → URL Configuration → Redirect URLs.
